# Quickstart

A minimal end-to-end Cynosure app.

## Install

<PackageManagerTabs command="@arshad-shah/cynosure-react @arshad-shah/cynosure-tokens" />

Prefer automation? The CLI detects your framework, writes the CSS import, and

## Wire the providers

`CynosureProvider` is the one wrapper every app mounts. It composes
`ThemeProvider` (owns theme state and toggles `data-theme` on `<html>`),
`TooltipProvider`, `DirectionProvider`, and `LocaleProvider` — and it **loads the
design tokens for you**, so there's no stylesheet to import. Each component's CSS
auto-loads when you import the component.

```tsx
// src/main.tsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import { CynosureProvider } from '@arshad-shah/cynosure-react';
import App from './App';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <CynosureProvider theme={{ defaultTheme: 'system' }}>
      <App />
    </CynosureProvider>
  </React.StrictMode>,
);
```

> Prefer to compose the providers yourself? `ThemeProvider`,
> `DirectionProvider`, `LocaleProvider`, and `TooltipProvider` are all exported
> individually — `ThemeProvider` is the one that loads the tokens.

## Your first button

The simplest Cynosure component is `Button`:

```tsx
// src/App.tsx
import { Button } from '@arshad-shah/cynosure-react';

export default function App() {
  return (
    <Button onClick={() => alert('Hello, Cynosure!')}>
      Click me
    </Button>
  );
}
```

## A full first screen

```tsx
// src/App.tsx
import {
  Button,
  Card,
  CardContent,
  CardHeader,
  Heading,
  Stack,
  Text,
} from '@arshad-shah/cynosure-react';

export default function App() {
  return (
    <Stack gap="6" padding="6" maxWidth="md" marginX="auto">
      <Heading level={1}>Hello, Cynosure</Heading>
      <Card>
        <CardHeader>
          <Heading level={2} size="lg">
            A minimal card
          </Heading>
        </CardHeader>
        <CardContent>
          <Stack gap="3">
            <Text>
              Cynosure ships primitives that render real HTML and components
              that compose those primitives.
            </Text>
            <Button>Primary action</Button>
          </Stack>
        </CardContent>
      </Card>
    </Stack>
  );
}
```

## Switch themes

```tsx
import { useTheme } from '@arshad-shah/cynosure-react';

function ThemeSwitcher() {
  const { theme, setTheme, themes } = useTheme();
  return (
    <select value={theme} onChange={(e) => setTheme(e.target.value)}>
      {themes.map((t) => (
        <option key={t} value={t}>{t}</option>
      ))}
    </select>
  );
}
```

## Ship a form

```tsx
import {
  Button,
  Form,
  FormControl,
  FormField,
  FormLabel,
  FormMessage,
  Input,
  Stack,
} from '@arshad-shah/cynosure-react';

export function ContactForm() {
  return (
    <Form onSubmit={(e) => { e.preventDefault(); /* … */ }}>
      <Stack gap="4">
        <FormField name="email" required>
          <FormLabel>Email</FormLabel>
          <FormControl>
            <Input type="email" />
          </FormControl>
          <FormMessage />
        </FormField>
        <Button type="submit">Send</Button>
      </Stack>
    </Form>
  );
}
```

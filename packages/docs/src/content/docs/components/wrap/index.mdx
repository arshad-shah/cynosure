## Independent row + column gap

`gap` controls both axes equally. Use `rowGap` and `columnGap` independently when the row distance should differ from the column distance after wrapping — common in tag clouds where a tighter column gap and a looser row gap reads cleanly.

<LivePreview example="wrap/row-column-gap" />

## Align and justify

`align` controls cross-axis alignment of items within a row; `justify` distributes items along the main axis. `align="center"` keeps mixed-height chips visually centered after wrapping.

## Recipes

- Tag list: `<Wrap gap="2">{tags.map((t) => <Chip key={t}>{t}</Chip>)}</Wrap>`.
- Filter bar: combine `Wrap` with `Chip` + `Checkbox` items so the bar reflows naturally on narrow viewports.
- For predictable column layouts (cards in a grid), prefer `SimpleGrid` — Wrap is for variable-width items where the column count is data-driven.

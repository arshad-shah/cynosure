## Space presets

`space` controls the section's vertical padding: `sm`, `md` (default), `lg`, `xl`. Use `lg` or `xl` for marketing pages; `sm` for compact tools.

<LivePreview example="section/space" />

## Nesting with Container

The canonical composition is `<Section><Container>...</Container></Section>`: Section owns vertical rhythm, Container owns horizontal measure. Together they produce the standard "padded, centered" page section.

## Recipes

- Landing-page sections: `<Section space="xl" aria-labelledby="cta-heading"><Container size="lg">...</Container></Section>`.
- Dashboard panels: `<Section space="sm">` keeps panels visually distinct without inflating the page.
- Alternate background colours per section via `background="bg.subtle"` to delineate without dividers.

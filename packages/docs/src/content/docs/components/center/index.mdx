## With a height floor

Center needs a non-zero height to do anything meaningful in the vertical axis. Set `minHeight` (token or raw value) so the canvas has room to center within.

## Recipes

- Loading state inside a card: `<Center minHeight="120px"><Spinner /></Center>`.
- Empty state placeholder: pair `Center` with `EmptyState`. Set `flex="1"` on the Center when it sits inside a flex parent so it claims the remaining space.
- For the entire viewport: nest a `Center` inside a `Box minHeight="100vh"` (or use the `screen` size token on `minHeight`).

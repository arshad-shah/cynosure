# src/adapters

Optional build-tool adapters. The package works without any of them (plain ESM + `.css` + `styles.inline`). Each adapter lives in `src/adapters/<tool>/`, exports one factory, has a contract test, and is documented in `docs/adapters.md`. `vite` is implemented (`cynosure({ theme, selector, stylesheet })` with `virtual:cynosure/theme.css` and `virtual:cynosure/inline`). `astro` is an Astro integration built on it (theme and stylesheet on every page, the saved-mode script inline in `<head>`, `htmlAttributes()` for `<html>`); it uses no Astro types. esbuild/extforge follows the same contract.

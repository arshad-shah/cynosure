# ChoiceBase

A native checkbox or radio, visually hidden under a Cynosure skin but still focusable, clickable and form-associated. It is a foundation: it has no visual opinions, and the composite that uses it draws the visible control.

## Who uses it

[Checkbox](?path=/docs/components-checkbox--docs), [Switch](?path=/docs/components-switch--docs), [RadioGroup](?path=/docs/components-radiogroup--docs) and [SegmentedControl](?path=/docs/components-segmentedcontrol--docs).

## When to use it directly

Only when building a new choice-style composite (a custom checkbox, radio or toggle look) that must behave like a real form control.

**Use a component instead when** you need a labelled control: [Checkbox](?path=/docs/components-checkbox--docs) or [Switch](?path=/docs/components-switch--docs) for on/off, [RadioGroup](?path=/docs/components-radiogroup--docs) for one of several, [SegmentedControl](?path=/docs/components-segmentedcontrol--docs) for a compact choice.

## Usage

```tsx
import { ChoiceBase } from "@arshad-shah/cynosure";

<ChoiceBase type="checkbox" name="terms" value="yes" indeterminate={partial} />
<ChoiceBase type="radio" name="size" value="md" />
```

## Props

It accepts every native input attribute except `type`, which is required and must be `"checkbox"` or `"radio"`.

<ArgTypes of={Stories} />

## Guarantees

- It stays focusable, clickable and form-associated (FormData, reset, required) without extra code.
- `indeterminate` sets the mixed state on the underlying input. It applies to checkboxes only.
- The ref reaches the native `<input>`.
- It adds the `cy-choice-base` class (its stylesheet is `styles/choice-base.css`), which hides it visually; any `className` you pass is kept alongside.

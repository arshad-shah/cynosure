# Cynosure

One small, themeable, accessible UI system for every product. Same feel and layout everywhere; each product changes its accent, its scale, and any token it needs.

```bash
pnpm add @arshad-shah/cynosure
```

```tsx
import "@arshad-shah/cynosure/styles.css";
import { CynosureTheme, createTheme, Button } from "@arshad-shah/cynosure";

const theme = createTheme({ accent: "#e8462e", scale: "compact" });

<CynosureTheme theme={theme} mode="system">
  <Button variant="solid" tone="accent">Export</Button>
</CynosureTheme>;
```

**What is here:**

- **Foundations:** the only modules with native elements (ButtonBase, LinkBase, InputBase, TextAreaBase, ChoiceBase, HiddenValue, DialogBase, Icon).
- **Controls:** Button, IconButton, CopyButton, Link, TextField, SearchField, TextArea, Select, Combobox, Checkbox, Switch, RadioGroup, SegmentedControl, Slider, ColorField, ThemeToggle. Every form control works in native forms (FormData, reset, required).
- **Structure:** Stack, Inline, Grid, Card, Toolbar, Tabs, Disclosure, Accordion, Tree.
- **Overlays:** Tooltip, Popover, Menu, Dialog, Sheet, CommandPalette and Toast, all in the browser top layer, sharing one Escape and outside-click stack.
- **Feedback and display:** Notice, EmptyState, ProgressBar, Steps, LoadingDots, Skeleton, DescriptionList, Badge, Kbd, Field.

**Use the toolbar** to switch mode, contrast, scale and product accent on every story, and to render under a **hostile host** stylesheet (Tailwind preflight plus aggressive globals). Cynosure must look identical either way.

- Works on a page, inside a shadow root (`@arshad-shah/cynosure/styles.inline`), and in extension popups.
- No runtime dependencies, no CSS-in-JS, no writes to `<html>`, `<head>` or `<body>`.
- Facet icons: 184 stroke icons in 15 categories, drawn on the Cynosure grid with softened squares and built-in micro-animations.
- One prop vocabulary everywhere: `size`, `tone`, `variant`, `color`, plus behaviour props. Every story has controls for all of them.

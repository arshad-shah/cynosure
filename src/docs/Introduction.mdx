# Cynosure

One small, themeable, accessible UI system for every product. Same feel and layout everywhere; each product changes its accent, its scale, and any token it needs.

```bash
pnpm add @arshad-shah/cynosure
```

```tsx
import "@arshad-shah/cynosure/styles.css";
import { CynosureTheme, createTheme, Button } from "@arshad-shah/cynosure";

const theme = createTheme({ accent: "#e8462e", scale: "compact" });

<CynosureTheme theme={theme} mode="system">
  <Button variant="solid" tone="accent">Export</Button>
</CynosureTheme>;
```

**What is here:**

- **Foundations:** the only modules with native elements (ButtonBase, LinkBase, InputBase, FileInputBase, TextAreaBase, ChoiceBase, HiddenValue, DialogBase, Icon) and the parts every component may use (HiddenValue, LiveRegion, Icon).
- **Controls:** Button, IconButton, CopyButton, Link, TextField, NumberField, SearchField, TextArea, Select, Combobox, TagInput, Checkbox, Switch, RadioGroup, SegmentedControl, Slider, DateField, TimeField, Checklist, Pagination, ColorField, ColorSwatches, KeyValueEditor, FileDrop, PathField, SignaturePad, SelectionFrame, CompareSlider, ThemeToggle, Choice, OptionList, HotkeyField, SortButton, RowActions. Every form control works in native forms (FormData, reset, required).
- **Structure:** AppShell (`useAppShell`), TitleBar, StatusBar, Container, PageHeader, Stack, Inline, Grid, ScrollArea, Divider, AspectRatio, Breadcrumbs, SideNav, SplitPane, Card, Toolbar, Tabs, Disclosure, Accordion, Tree, SortableList, VirtualList, Calendar, DocumentViewport, PanZoomCanvas, ZoomControls, Section, SiteHeader, SiteFooter, SkipLink, ListRow (`ListRows`), OverlayFrame, VisuallyHidden.
- **Overlays:** Tooltip, HoverCard, Popover, FloatingToolbar (`DockedToolbar`), Menu, Menubar, ContextMenu, Dialog, ProgressOverlay, Sheet, CommandPalette (`useHotkey`), Toast (`Toaster`, `useToast`). The floating ones sit in the browser top layer and share one Escape and outside-click stack.
- **Feedback and display:** Notice, EmptyState, ErrorBoundary, ProgressBar, Steps, LoadingDots, Skeleton, DescriptionList, Stat, List, Table, Text, Heading, Prose, Avatar (`AvatarGroup`), IconTile, Image, CodeBlock, Announcer (`useAnnounce`), Badge, Kbd, Field, DataGrid, HighlightedText, ChatMessage, QRCode, DeviceFrame.

**Use the toolbar** to switch mode, contrast, scale and product accent on every story, and to render under a **hostile host** stylesheet (Tailwind preflight plus aggressive globals). Cynosure must look identical either way.

- Works on a page, inside a shadow root (`@arshad-shah/cynosure/styles.inline`), and in extension popups.
- One runtime dependency (`@arshad-shah/detent`, for pointer dragging), no CSS-in-JS, no writes to `<html>`, `<head>` or `<body>`.
- Icons: 274 Facet stroke icons in 17 categories, drawn on the Cynosure grid with softened squares and built-in micro-animations; 98 official brand marks; and `iconToSvg` for pages without React.
- One prop vocabulary everywhere: `size`, `tone`, `variant`, `color`, plus behaviour props. Every story has controls for all of them.

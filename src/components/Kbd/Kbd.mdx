# Kbd

A keyboard shortcut shown as drawn key caps. Screen readers get a spoken combination instead ("Control plus K").

<Canvas of={Stories.ReadsAsAKeyCombination} />

## Usage

```tsx
import { Kbd } from "@arshad-shah/cynosure";

<Kbd keys={["Ctrl", "K"]} />
<Kbd keys={["Cmd", "Shift", "P"]} size="sm" />
<Kbd keys={["⌘", "K"]} label="Command K" />
```

`keys` lists the keys in order. Keys are joined by a drawn separator, not a "+" character. `size` is `sm`, `md` (default) or `lg`.

## Spoken text

Common names are spoken in full: Ctrl as Control, Cmd as Command, Esc as Escape, and so on. For symbols or unusual keys, set `label` to say what you mean.

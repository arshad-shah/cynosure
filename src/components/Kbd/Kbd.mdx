# Kbd

A keyboard shortcut shown as drawn key caps. Screen readers get a spoken combination instead ("Control plus K").

<Canvas of={Stories.ReadsAsAKeyCombination} />

## Usage

```tsx
import { Kbd } from "@arshad-shah/cynosure";

<Kbd keys={["Ctrl", "K"]} />
<Kbd keys={["Cmd", "Shift", "P"]} size="sm" />
<Kbd keys={["⌘", "K"]} label="Command K" />
```

`keys` lists the keys in order. Keys are joined by a drawn separator, not a "+" character. `size` is `sm`, `md` (default) or `lg`.

## A shortcut for this platform

`keys` also takes a shortcut as `useHotkey` writes it (`"mod+shift+k"`), shown with this platform's names: `mod` is Cmd on Apple platforms and Ctrl elsewhere, `alt` is Option or Alt, `meta` is Cmd or Win. Pass the same string to `useHotkey` and to Kbd, so the hint always matches the shortcut.

```tsx
<Kbd keys="mod+shift+k" />
```

<Canvas of={Stories.AShortcutForThisPlatform} />

On touch-only screens (no hover, coarse pointer) a shortcut string is hidden, since there is no keyboard to press it on. Keys given as a list are content (a help page) and stay.

## Spoken text

Common names are spoken in full: Ctrl as Control, Cmd as Command, Esc as Escape, and so on. For symbols or unusual keys, set `label` to say what you mean.

## Attributes

`id`, any `data-*` attribute, `role`, any `aria-*` attribute and the `ref` go to the root element.

## Theming

Tokens: `--cy-kbd-radius`, `--cy-kbd-bg` and `--cy-kbd-border`.

```ts
createTheme({ components: { kbd: { radius: "6px" } } });
```

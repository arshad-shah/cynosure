# Choice

The row a choice control sits in: the control, its label and an optional description, the whole row clickable. [Checkbox](?path=/docs/components-controls-checkbox--docs), [Switch](?path=/docs/components-controls-switch--docs) and each [RadioGroup](?path=/docs/components-controls-radiogroup--docs) option are Choice rows that draw their own control.

<Canvas of={Stories.LabelNamesAndTogglesTheControl} />

## When to use

- Building a new kind of choice control (a star, a coloured chip) that needs the same label, description, forms and touch behaviour as a checkbox.

**Use something else when:**
- you need a checkbox: [Checkbox](?path=/docs/components-controls-checkbox--docs)
- you need an on/off setting: [Switch](?path=/docs/components-controls-switch--docs)
- one option of several: [RadioGroup](?path=/docs/components-controls-radiogroup--docs) or [SegmentedControl](?path=/docs/components-controls-segmentedcontrol--docs)

## Usage

```tsx
import { Choice, ChoiceBase } from "@arshad-shah/cynosure";

<Choice
  label="Show hidden files"
  description="Dotfiles and system folders."
  onChange={setShown}
  control={(input) => (
    <span className="my-star">
      <ChoiceBase {...input} type="checkbox" />
    </span>
  )}
/>
```

`control` receives the input's props: its `id`, `aria-labelledby`, `aria-describedby`, `tabIndex`, `checked` or `defaultChecked`, `onChange`, and `name`, `value`, `required` and `disabled`. Spread them onto [ChoiceBase](?path=/docs/foundations-choicebase--docs), which hides the native input over your drawing. The input must be a direct child of the element `control` returns. `onChange` on Choice receives the new `checked` boolean.

## Done style

`strikeWhenChecked` strikes through and mutes the label while the input is checked (and not indeterminate), and mutes the description with it. An input placed inside the label does not count.

<Canvas of={Stories.StrikeWhenCheckedAndItsTokens} />

## Cards

`variant="card"` draws the row as a bordered card with `media` (a thumbnail, a font sample, a swatch) above the label. The card shows the state, with the accent border and soft background while its input is checked and the focus ring while focused, so the control should hide its own look. RadioGroup's picture cards and Checkbox's `variant="card"` are Choice cards.

## Behaviour and accessibility

| Input | Result |
| --- | --- |
| Click or tap the control, label or description | Toggles the input |
| <kbd>Space</kbd> on the focused input | Toggles it |

- **Name and description:** the label names the input and the description is linked with `aria-describedby`.
- **Forms:** the input is native, so `FormData`, reset and `required` work as the browser does them.
- **Named and described from outside:** `aria-labelledby` names the input by other elements (a column heading) instead of its label; pair it with `labelHidden`, which keeps the label for assistive tech but takes no space. Your `aria-describedby` ids are read before the description.
- **Roving focus:** `tabIndex={-1}` reaches the input, for a grid or list that moves focus itself.
- **The change event:** `onChange(checked, event)`. The event's `nativeEvent` is the click that toggled the input, so `event.nativeEvent.shiftKey` tells a Shift+click (select a range of rows) from a plain one.
- **Disabled:** the input is disabled and the row is dimmed with a not-allowed cursor.
- **Done style:** the checked state is what is announced; the strike only shows it. In forced colours the strike stays, in the system text colour; under reduced motion the change is instant (no transition), but the muted colour and strike still apply.

## Touch

The row is at least 24px tall, and 44px on coarse pointers, where the control is centred on the text.

## Theming

| Token | Controls |
| --- | --- |
| `--cy-choice-gap` | Space between the control and the text. Default `--cy-space-4`. |
| `--cy-choice-done-color` | Label and description colour of a checked `strikeWhenChecked` row. Default `--cy-color-muted`. Checkbox sets it from `--cy-checkbox-done-color`. |
| `--cy-choice-strike-width` | Thickness of the strike. Default: the border width, or 1/16 of the text size when that is larger. Checkbox sets it from `--cy-checkbox-strike-width`. |
| `--cy-choice-card-radius` | Corner radius of a card. Default `--cy-radius-card`. |
| `--cy-choice-card-padding` | Padding inside a card. Default `--cy-space-3`. |
| `--cy-choice-card-checked-background` | Background of a checked card. Default `--cy-color-accent-soft`. |
| `--cy-choice-media-background` | Background behind a card's picture. Default `--cy-color-bg`. |
| `--cy-choice-media-min-height` | Least height of a card's picture. Default 4rem. |

```ts
createTheme({ components: { choice: { gap: "12px" } } });
```

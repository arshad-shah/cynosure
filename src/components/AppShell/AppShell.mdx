# AppShell

The frame of an app: a top bar, the navigation beside the content, and the main region. When there is not enough room, the navigation moves into a drawer opened from a menu button.

<Canvas of={Stories.NavigationBesideTheContent} />

## When to use

- **The outer layout of an app** with a persistent navigation.

**Use something else when:**
- the page is a document or a marketing page: your own layout with [Prose](?path=/docs/components-prose--docs) and [Stack](?path=/docs/components-stack--docs)
- you only need the navigation: [SideNav](?path=/docs/components-sidenav--docs)

## Usage

```tsx
import { AppShell, SideNav } from "@arshad-shah/cynosure";

<div style={{ blockSize: "100dvh" }}>
  <AppShell header={<Brand />} nav={<SideNav label="Main" items={items} current={route.id} />}>
    <Page />
  </AppShell>
</div>
```

The shell fills its container's height. The content and the navigation scroll on their own while the bar stays in place.

<Canvas of={Stories.ContentScrollsOnItsOwn} />

## Narrow screens

Below `collapseBelow` (768px of the shell's own width) the navigation leaves the layout. A menu button appears at the start of the bar and opens it in a start-side [Sheet](?path=/docs/components-sheet--docs). Choosing a link or item closes the drawer; opening a group does not.

## Behaviour and accessibility

- **Landmarks:** the bar is a `<header>` (banner), the navigation keeps its own `<nav>`, and the content is `<main>`.
- **Skip link:** the first Tab shows "Skip to content"; Enter moves focus to `<main>` without changing the URL, so your router stays in charge.
- **Drawer:** a modal Sheet named "Navigation" with focus trapping and Escape; focus returns to the menu button when it closes. The button reports `aria-expanded`.
- **Touch:** the menu button's hit area is at least 44px on touch screens.
- **Direction:** the navigation is on the right in right-to-left text, and the drawer slides from that side.
- All built-in text is in `labels`.

## Theming

Tokens: `--cy-app-shell-nav-background`, `--cy-app-shell-header-background` and `--cy-app-shell-border`.

# SearchField

A [TextField](?path=/docs/components-textfield--docs) preset for search: it has a search icon, is clearable, and submits on Enter. For a plain text input, use TextField.

<Canvas of={Stories.SubmitsOnEnter} />

## When to use

- A search or filter box above a list, table or document.
- Search inside a [Toolbar](?path=/docs/components-toolbar--docs).

**Use something else when:**
- the input is not a search: [TextField](?path=/docs/components-textfield--docs)
- the user picks from a fixed list: [Select](?path=/docs/components-select--docs)

## Usage

```tsx
import { SearchField } from "@arshad-shah/cynosure";

<SearchField label="Search documents" onChange={setQuery} onSubmit={runSearch} />
<SearchField label="Search" labelHidden size="sm" />
```

## Submit and clear

`onSubmit(value)` runs on Enter. It is ignored while an IME composition is active, so confirming a candidate never submits early. The clear button shows while the field has a value; set `clearable={false}` to remove it.

<Canvas of={Stories.EscapeClearsThenBlurs} />

## Match count

`trailing` shows status text inside the field, at its end: a match count such as "1 of 3". Each new text is announced politely, once, through a live region that is always in the page; the visible copy is hidden from screen readers so it is not read twice. It is for text only; buttons such as "next match" go in `addonEnd`, after it.

```tsx
<SearchField label="Find" value={query} onChange={setQuery} trailing={query ? `${at} of ${total}` : undefined} />
```

## Props

SearchField takes every [TextField](?path=/docs/components-textfield--docs) prop except `type` and `iconStart`, plus `onSubmit` and `trailing`.

<ArgTypes of={Stories} />

## Behaviour and accessibility

| Input | Result |
| --- | --- |
| <kbd>Enter</kbd> | Calls `onSubmit` with the current value (not during IME composition) |
| <kbd>Escape</kbd> | Clears the field if it has a value; when empty, blurs it |

- **Role:** it is a native `type="search"` input, exposed as a search box.
- **Label:** a visible label is preferred. `labelHidden` hides it visually but it still names the field.
- **Refs:** the ref points at the input element.
- **Trailing text:** announced politely when it changes (a `role="status"` region); the visible copy is `aria-hidden`.

## Theming

The trailing text has `--cy-search-field-trailing-color` and `--cy-search-field-trailing-font-size`. The field itself uses the TextField tokens: `--cy-text-field-{height-sm,height-md,height-lg,radius,padding-inline,bg,border,soft-bg}`.

```ts
createTheme({ components: { textField: { radius: "999px" }, searchField: { trailingFontSize: "12px" } } });
```

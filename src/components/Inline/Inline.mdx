# Inline

Lays children out in a row with a gap from the space scale. For a column, use [Stack](?path=/docs/components-stack--docs); Inline is a Stack in a row, with its items centred and an optional `wrap`.

<Canvas of={Stories.RowWithTokenGap} />

## When to use

- Toolbars, button rows, badge lists, label-and-value pairs.
- Use `wrap` when items may not fit on one line.

## Usage

```tsx
import { Inline } from "@arshad-shah/cynosure";

<Inline gap="4" align="center">
  <Badge>Draft</Badge>
  <Button>Publish</Button>
</Inline>
<Inline as="ul" gap="2" wrap justify="between">…</Inline>
<Inline padding="4" paddingInline="6">…</Inline>
```

`gap` is a space token from `"0"` to `"10"` (default `"3"`). `align` is `start`, `center`, `end`, `stretch` or `baseline`. `justify` is `start`, `center`, `end` or `between`. `as` picks a neutral element (`div`, `section`, `ul`, `ol`, `nav`, `aside`, `header`, `footer`, `span`).

<Canvas of={Stories.DefaultsAndLayoutProps} />

## Padding

`padding` pads all four sides with a space token. `paddingInline` (the sides) and `paddingBlock` (top and bottom) each win over `padding` for their axis, and `"0"` counts as a value. The padding is inside the row's width.

```tsx
<Inline padding="4" paddingInline="6">…</Inline>
```

<Canvas of={Stories.PaddingUsesSpaceTokens} />

## Taking the free space

A child Stack or Inline with `grow` takes the free space in the row, so the items after it sit at the end (a status bar). Inline also takes `shrink`, `fill`, `minSize` and `overflow`; see [Stack](?path=/docs/components-stack--docs) for app shells.

```tsx
<Inline gap="2">
  <Text>main</Text>
  <Inline grow>…</Inline>
  <Text>Ln 1, Col 1</Text>
</Inline>
```

## Notes

- `as` never renders an interactive element.
- `className` and `style` are for layout only.
- The gap and the padding are space tokens (`--cy-space-*`), so they follow the theme's spacing.
- A nested Inline has no padding unless it asks for it; it never inherits its parent's.

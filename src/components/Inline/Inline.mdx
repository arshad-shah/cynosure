# Inline

Lays children out in a row with a gap from the space scale. For a column, use [Stack](?path=/docs/components-structure-stack--docs); Inline is a Stack in a row, with its items centred and an optional `wrap`.

<Canvas of={Stories.RowWithTokenGap} />

## When to use

- Toolbars, button rows, badge lists, label-and-value pairs.
- Use `wrap` when items may not fit on one line.

## Usage

```tsx
import { Inline } from "@arshad-shah/cynosure";

<Inline gap="4" align="center">
  <Badge>Draft</Badge>
  <Button>Publish</Button>
</Inline>
<Inline as="ul" gap="2" wrap justify="between">…</Inline>
<Inline padding="4" paddingInline="6">…</Inline>
```

`gap` is a space token from `"0"` to `"10"` (default `"3"`). `align` is `start`, `center`, `end`, `stretch` or `baseline`. `justify` is `start`, `center`, `end` or `between`. `as` picks a neutral element (`div`, `section`, `ul`, `ol`, `nav`, `aside`, `header`, `footer`, `span`).

<Canvas of={Stories.DefaultsAndLayoutProps} />

## Padding

`padding` pads all four sides with a space token. `paddingInline` (the sides) and `paddingBlock` (top and bottom) each win over `padding` for their axis, and `"0"` counts as a value. The padding is inside the row's width.

```tsx
<Inline padding="4" paddingInline="6">…</Inline>
```

<Canvas of={Stories.PaddingUsesSpaceTokens} />

## Taking the free space

A child Stack or Inline with `grow` takes the free space in the row, so the items after it sit at the end (a status bar). Inline also takes `shrink`, `fill`, `minSize` and `overflow`; see [Stack](?path=/docs/components-structure-stack--docs) for app shells.

```tsx
<Inline gap="2">
  <Text>main</Text>
  <Inline grow>…</Inline>
  <Text>Ln 1, Col 1</Text>
</Inline>
```

## Attributes and events

`id`, `role`, any `aria-*` or `data-*` attribute, `tabIndex`, `dir`, `lang` and every event handler (pointer, keyboard, drag and drop, focus) go to Inline's element, and so does `ref`: a Inline can be a drop zone, a landmark or a group without a wrapper `div`. It stays layout: give a box that reacts to clicks or keys a role and a name, or use the component made for it (Button, Card, ListRow).

## Meta line

`separator` puts a mark between the children: `dot` for a meta line under a title ("PDF · 3 pages · 1.2 MB"), `line` for a thin upright rule. Each child, text included, becomes one item, and empty children (`null`, `false`) are left out, so a value that is missing leaves no stray mark. The mark is drawn in the gap by CSS, not typed, so screen readers read only the values; render it `as="ul"` when the values are a list worth announcing. Colour and size come from `--cy-inline-separator-color` and `--cy-inline-separator-size`. For terms with values, use [DescriptionList](?path=/docs/components-feedback-and-display-descriptionlist--docs) with `layout="inline"`.

```tsx
<Text as="div" size="sm" tone="muted">
  <Inline separator="dot" gap="2" wrap>
    PDF
    {pages} pages
    {size && formatBytes(size)}
  </Inline>
</Text>
```

## Blocking a region

`inert` blocks the row while a job holds the page: nothing inside can be focused, clicked or typed into, and assistive technology skips it (the HTML `inert` attribute, set as a property so React 18, React 19 and Preact all honour it). `disabled` does the same and dims the row as a disabled Button is. Clear it to give the row back. Tell people why it is blocked outside it, with a ProgressBar or a status Text.

```tsx
<Inline disabled={job.running}>…</Inline>
```

## Notes

- `as` never renders an interactive element.
- `className` and `style` are for layout only.
- The gap and the padding are space tokens (`--cy-space-*`), so they follow the theme's spacing.
- A nested Inline has no padding unless it asks for it; it never inherits its parent's.

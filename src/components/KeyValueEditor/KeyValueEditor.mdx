# KeyValueEditor

Editable key and value pairs, such as HTTP headers or environment variables, in rows or as text.

<Canvas of={Stories.EditPairs} />

## When to use

- **A list of named values** people add to, edit, reorder and switch off: headers, query parameters, metadata.

**Use something else when:**
- the keys are fixed: a form of [TextField](?path=/docs/components-controls-textfield--docs)s
- the values are short tags without keys: [TagInput](?path=/docs/components-controls-taginput--docs)
- the pairs are only shown: [DescriptionList](?path=/docs/components-feedback-and-display-descriptionlist--docs)

## Usage

```tsx
import { KeyValueEditor, type KeyValuePair } from "@arshad-shah/cynosure";

<KeyValueEditor label="Headers" pairs={headers} onChange={setHeaders} />
```

Each pair is `{ id, key, value, enabled?, secret? }`. Give new pairs from your data a stable `id`; pairs added in the editor get one of their own. `secret: true` masks the value.

"Edit as text" turns every pair into a `key: value` line (with `# ` in front of a pair that is switched off), so a block of headers can be pasted in at once.

<Canvas of={Stories.EditAsText} />

## Files as values

For multipart form fields, `allowFiles` adds a button to each row that picks a file for its value (`accept` limits the types). The pair gets `file`, and `value` holds the file's name.

```tsx
<KeyValueEditor label="Form fields" pairs={fields} onChange={setFields} allowFiles accept="image/*" />
```

<Canvas of={Stories.FileValuedRows} />

## Letting the user mark a pair secret

`rowTypes` adds a Type select to each row ("Type (token)"), so the user decides what a pair is: Text, or Secret, which masks the value and sets `secret: true` on the pair. With `allowFiles` it also offers File: choosing it opens the file picker, and choosing Text again takes the file away.

```tsx
<KeyValueEditor label="Variables" pairs={vars} onChange={setVars} rowTypes />
```

## Behaviour and accessibility

- **Names:** every field is named for its row ("Value (Authorization)"), and so are the checkbox ("Use Authorization") the remove button ("Remove Authorization") and, with `rowTypes`, the Type select ("Type (Authorization)").
- **Reordering:** drag a row's grip, or focus it and press Space, the arrows, then Space (Escape cancels); moves are announced.
- **Focus:** Add focuses the new row's key field; removing a row focuses the row that took its place, or Add.
- **Touch:** grips and buttons have 44px hit areas on touch screens.

## Theming

Tokens: `--cy-key-value-editor-gap`, and `--cy-key-value-editor-type-width` (the Type select's width with `rowTypes`, default 8rem). Rows, fields and buttons follow the SortableList, TextField and Button tokens.

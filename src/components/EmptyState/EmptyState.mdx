# EmptyState

What to show where content will be: no items yet, no search results, nothing selected. It says what is missing and offers the next step.

<Canvas of={Stories.HeadingAndNextStep} />

## When to use

- **A list or area with nothing in it yet**, with a way to add the first item.
- **No results** for a search or filter, with a way to widen it.

**Use something else when:**
- something went wrong: a [Notice](?path=/docs/components-notice--docs)
- content is still loading: a loading indicator such as [LoadingDots](?path=/docs/components-loadingdots--docs)

## Usage

```tsx
import { Button, EmptyState } from "@arshad-shah/cynosure";
import { search } from "@arshad-shah/cynosure/icons";

<EmptyState
  icon={search}
  title="No matches"
  description="Try fewer words or clear the filters."
```

## Behaviour and accessibility

- **Heading:** the title is a real `h2` to `h6`, so it shows up in the page outline and heading navigation.
- **Icon:** decorative (`aria-hidden`).
- **Contrast:** title and description are at least 4.5:1 on the page background in light and dark modes.
- It has no interaction of its own; the actions are ordinary Buttons.

## Theming

Tokens: `--cy-empty-state-gap`, `--cy-empty-state-padding` and `--cy-empty-state-max-width` (line length of the text).

```ts
createTheme({ components: { emptyState: { maxWidth: "48ch" } } });
```

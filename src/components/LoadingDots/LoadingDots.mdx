# LoadingDots

Three dots that pulse in sequence, or a turning spinner, for short waits of unknown length. For a task with known progress, show the progress itself.

<Canvas of={Stories.Default} />

## When to use

- Inside a button while it saves ([Button](?path=/docs/components-button--docs) does this for you with `loading`).
- Inline status text, list footers, a panel that is still loading.

## Usage

```tsx
import { LoadingDots } from "@arshad-shah/cynosure";

<LoadingDots label="Saving document" />        // announced
<LoadingDots size="lg" tone="accent" />        // decorative
<LoadingDots color="#14b8a6" speed="slow" />   // one-off colour
```

## Announcing it

By default the dots are decorative. Set `label` to give them `role="status"` and an accessible name. Leave it out when the surrounding control already reports the state, as Button does with `aria-busy`.

<Canvas of={Stories.Labelled} />

## Size, tone and speed

`size` defaults to `inherit`, which follows the surrounding font size; `sm`, `md` and `lg` are fixed. `tone` is any tone, `muted`, or `inherit` (the current text colour). `speed` is `slow`, `normal` or `fast`. `color` takes any CSS colour for one-off cases; prefer tones.

## Spinner

`variant="spinner"` draws the `loader` icon turning instead of the dots. It is one em square, so it sits where an icon would: a statement gutter, a tree row, a tool call's header, beside a button's text. It takes the same `size`, `tone`, `color`, `speed` and `label`.

```tsx
<Button>
  <LoadingDots variant="spinner" /> Connecting
</Button>
```

## Behaviour and accessibility

- **Reduced motion:** with the OS setting or `createTheme({ motion: "reduced" })`, the dots stay still and fully visible, and the spinner stops turning.
- **Without a label** the dots or spinner are `aria-hidden`. The spinner's icon is always decorative; with a label the root is the status.

## Theming

Tokens: `--cy-loading-dots-dot-size`, `--cy-loading-dots-gap`, `--cy-loading-dots-color`, `--cy-loading-dots-duration` and `--cy-loading-dots-size-{sm,md,lg}`.

```ts
createTheme({ components: { loadingDots: { gap: "0.4em" } } });
```

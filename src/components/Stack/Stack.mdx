# Stack

Lays children out in a column with a gap from the space scale. For a row, use [Inline](?path=/docs/components-inline--docs).

<Canvas of={Stories.GapsUseSpaceTokens} />

## When to use

- Forms, settings panels, card content, any vertical rhythm.
- Instead of margins on each child.

## Usage

```tsx
import { Stack } from "@arshad-shah/cynosure";

<Stack gap="4">
  <TextField label="Name" />
  <TextField label="Email" />
</Stack>
<Stack as="ul" gap="2" align="start">…</Stack>
<Stack padding="6">…</Stack>
```

`gap` is a space token from `"0"` to `"10"` (default `"4"`). `direction` is `column` (default) or `row`; a row that centres its items and can wrap is [Inline](?path=/docs/components-inline--docs), which is a Stack in a row. `align` is `start`, `center`, `end`, `stretch` or `baseline`. `justify` is `start`, `center`, `end` or `between`. `as` picks a neutral element (`div`, `section`, `ul`, `ol`, `nav`, `aside`, `header`, `footer`, `span`).

<Canvas of={Stories.DefaultsAndLayoutProps} />

## Padding

`padding` pads all four sides with a space token. `paddingInline` (the sides) and `paddingBlock` (top and bottom) each win over `padding` for their axis, and `"0"` counts as a value. The padding is inside the stack's width. For the page's own column and gutters, use [Container](?path=/docs/components-container--docs).

```tsx
<Stack padding="6" paddingBlock="8">…</Stack>
```

## Notes

- `as` never renders an interactive element.
- `className` and `style` are for layout only.
- The gap and the padding are space tokens (`--cy-space-*`), so they follow the theme's spacing.
- A nested Stack has no padding unless it asks for it; it never inherits its parent's.

# ThemeToggle

A light, dark or system switch with sun, moon and monitor icons. It is a [SegmentedControl](?path=/docs/components-controls-segmentedcontrol--docs) wired to `useColorMode`. Pair it with `CynosureTheme` so the chosen mode is applied.

<Canvas of={Stories.SelectsAndPersists} />

## When to use

- A colour-mode switch in an app header, settings page or extension popup.

**Use something else when:**
- you need a different set of modes or other labels and icons: [SegmentedControl](?path=/docs/components-controls-segmentedcontrol--docs)

## Usage

Uncontrolled, it manages and persists the mode itself. Pass the mode to `CynosureTheme` through `useColorMode`:

```tsx
import { CynosureTheme, ThemeToggle, useColorMode } from "@arshad-shah/cynosure";

function App() {
  const { mode } = useColorMode();
  return (
    <CynosureTheme mode={mode}>
      <ThemeToggle />
      {/* app */}
    </CynosureTheme>
  );
}
```

<Canvas of={Stories.UncontrolledToggleDrivesThePage} />

## Controlled use

Pass `value` and `onChange(mode)` to own the state. `mode` is `"light"`, `"dark"` or `"system"`.

```tsx
<ThemeToggle value={mode} onChange={setMode} size="sm" />
```

## One button

`variant="cycle"` is one icon [IconButton](?path=/docs/components-controls-iconbutton--docs) that steps light, dark, system, for tight headers. It shows the current mode's icon, and its name says the current mode and the next ("Colour mode: Light. Switch to Dark"); `labels.cycle(current, next)` replaces it.

<Canvas of={Stories.OneButtonCycle} />

## Persistence

Uncontrolled mode is stored in `localStorage` by default. Pass `storage` (any `{ get, set }` object, sync or async, such as one backed by `chrome.storage`) to persist elsewhere. `storageKey` (default `cy-color-mode`) is the key it is saved under: give each product on a shared origin its own, and pass the same one to `themeInitScript({ key })`. Toggles on one `storageKey` follow each other, also across tabs: localStorage's `storage` event by default, or the storage's `subscribe(key, onChange)` when it has one.

## Behaviour and accessibility

- **Names:** the group is named "Colour mode" and the options "Light", "Dark" and "System". Override them with `labels` (`label`, `light`, `dark`, `system`, and `cycle` for the one-button variant) when you localise.
- **Keyboard:** it behaves as its SegmentedControl: arrow keys move and select, and activating the current option does nothing.
- **Icon-only:** the icons carry no visible text, but each option keeps its accessible name.

<Canvas of={Stories.KeyboardAndLabels} />

## Theming

ThemeToggle has no tokens of its own. It uses the SegmentedControl tokens: `--cy-segmented-control-{radius,track-bg,active-bg,padding}`. The `cycle` variant is an IconButton and takes its tokens.

```ts
createTheme({ components: { segmentedControl: { radius: "999px" } } });
```

# Notice

An inline message about part of the page: a status, a warning or an error that stays in place until it is resolved or the person dismisses it.

<Canvas of={Stories.RolesByTone} />

## When to use

- **A lasting condition** of the page or a section: sync paused, read-only mode, a quota close to its limit.
- **An error that is not about one field**, such as a failed import.

**Use something else when:**
- the message is a passing confirmation: a [Toast](?path=/docs/components-toast--docs)
- the error belongs to one field: that field's error text
- the person must answer before going on: [Dialog](?path=/docs/components-dialog--docs)

## Usage

```tsx
import { Button, Notice } from "@arshad-shah/cynosure";

<Notice tone="warning" title="Storage almost full" action={<Button size="sm">Manage</Button>} dismissible>
  You have used 95% of your space.
</Notice>
```

Without `onDismiss`, the close button hides the Notice by itself. With `onDismiss`, you decide: remove it from your state to hide it.

## Narrow containers

The Notice measures its own width. Below 26rem the actions move under the text, so it fits side panels and extension popups.

## Behaviour and accessibility

| Input | Result |
| --- | --- |
| Close button | Hides it (or calls `onDismiss`) |

- **Role:** `role="alert"` for `tone="danger"`, which screen readers announce even when it appears already filled. Every other tone is `role="status"`: changes to its content are announced politely, but a status Notice that mounts with its text already in it is usually only read in place.
- **To announce a non-danger message** that appears later, keep the Notice mounted and change its content, or use a [Toast](?path=/docs/components-toast--docs), which is built to be announced once.
- **Icon:** decorative; the tone is also carried by the words.
- **Contrast:** title and body are at least 4.5:1 in every tone, in light and dark modes.

## Touch

The close button keeps a 44px hit area on coarse pointers.

## Theming

Tokens: `--cy-notice-radius`, `--cy-notice-padding` and `--cy-notice-soft-mix` (how strongly the tone tints the background).

```ts
createTheme({ components: { notice: { radius: "8px", softMix: "14%" } } });
```

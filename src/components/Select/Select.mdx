# Select

Picks one option from a list that opens on demand. The trigger is a Cynosure button and the list opens in the top layer, so it is never clipped. For a short list that should stay visible, use [RadioGroup](?path=/docs/components-radiogroup--docs).

<Canvas of={Stories.ClickToOpenAndSelect} />

## When to use

- Five or more options, or a list that would take too much room as radios.
- A value that is submitted with a form (a country, a language, a database).
- Options that benefit from a description or an icon.

**Use something else when:**
- there are only a few options: [RadioGroup](?path=/docs/components-radiogroup--docs) or [SegmentedControl](?path=/docs/components-segmentedcontrol--docs)
- the user types free text: [TextField](?path=/docs/components-textfield--docs)

## Usage

```tsx
import { Select } from "@arshad-shah/cynosure";

<Select
  label="Fruit"
  name="fruit"
  placeholder="Choose a fruit"
  options={[
    { value: "apple", label: "Apple" },
    { value: "pear", label: "Pear", description: "Seasonal" },
    { value: "plum", label: "Plum", disabled: true },
  ]}
  onChange={setFruit}
/>
```

## Controlled use

Pass `value` and `onChange(value)` to own the state, or `defaultValue` to start with a selection.

## Long lists and labels

The list has a maximum height and scrolls. Long labels truncate with an ellipsis in the trigger and the list. The list opens above the trigger when there is no room below.

<Canvas of={Stories.ManyOptionsScrollAndTruncate} />

## Options and states

- **`variant`:** `outline` (default) or `soft`.
- **`size`:** `sm`, `md` or `lg`.
- **`error` and `description`:** shown under the field and linked to the trigger.
- **`labels`:** override `placeholder`, `empty` (no options) and `required` (validation message).
- **`labelHidden`:** hides the label visually while it still names the trigger. Prefer a visible label.

## Coloured icons

`iconTone` and `iconColor` colour an option's icon and mean what [Icon](?path=/docs/foundations-icon--docs)'s `tone` and `color` mean: `iconTone` is a semantic colour (`accent`, `neutral`, `danger`, `success`, `warning`, `info`, `muted`), `iconColor` is any CSS colour and overrides it (`brand` draws a brand mark in its owner's colour). The colour shows in the list, on the highlighted and the selected option, and in the trigger once the option is chosen. Without the two fields an icon takes the text colour.

<Canvas of={Stories.OptionIconsKeepTheirColourInTheListAndTheTrigger} />

A disabled option shows its icon without the colour, muted with the rest of the row, and so does the trigger of a disabled Select. Tone colours keep a contrast of 3:1 against the highlight. With your own colour, check it in light and dark. The label must make sense without the colour.

## Behaviour and accessibility

| Input | Result |
| --- | --- |
| Click, <kbd>Enter</kbd>, <kbd>Space</kbd>, <kbd>ArrowDown</kbd>, <kbd>ArrowUp</kbd> | Opens the list |
| Arrow keys, <kbd>Home</kbd>, <kbd>End</kbd>, <kbd>PageUp</kbd>, <kbd>PageDown</kbd> | Move through options, skipping disabled ones |
| <kbd>Enter</kbd>, <kbd>Space</kbd>, <kbd>Tab</kbd> | Select the active option |
| <kbd>Escape</kbd> | Closes without changing the value |
| Typing | Jumps to a matching option (ignored during IME composition) |

- **Pattern:** a select-only combobox following the WAI-ARIA authoring practices, with a `listbox` of `option`s.
- **Forms:** a hidden input carries `name` and the value, so `FormData`, reset and `required` validation work.
- **Outside click:** closes the list.

## Touch

On coarse pointers (phones and tablets) option rows grow to 44px.

## Theming

Tokens: `--cy-select-{radius,bg,border,list-bg,list-shadow,list-max-height,option-active-bg}`. The list is an [OptionList](?path=/docs/components-optionlist--docs): the `list-*` and `option-*` tokens set its `--cy-option-list-*` tokens.

```ts
createTheme({ components: { select: { radius: "10px", listMaxHeight: "240px" } } });
```

# NumberField

A field for numbers. People type in their own format or step the value with the keyboard or the − and + buttons; your code gets a number.

<Canvas of={Stories.SpinButtonWithItsValue} />

## When to use

- **Quantities, amounts, limits, measurements**: values people may want to nudge up and down.

**Use something else when:**
- the value is picked on a scale and the exact number matters less: [Slider](?path=/docs/components-controls-slider--docs)
- it is digits that are not a quantity (a phone number, a code, a card number): [TextField](?path=/docs/components-controls-textfield--docs) with `inputMode="numeric"`

## Usage

```tsx
import { NumberField } from "@arshad-shah/cynosure";

<NumberField label="Seats" value={seats} onChange={setSeats} min={1} max={50} />
```

`onChange` fires when a value is committed: on each step, on Enter, and when leaving the field after typing. It receives a number, or `null` when the field is emptied.

## Live values while typing

`commit="input"` also applies the typed text as it is typed, whenever it reads as a number within `min` and `max`: a preview follows the keys. Emptying the field applies `null` at once, unless it is `required`, when the value stays until a number is typed. Text that is out of range or unreadable is not applied until it is again, and the text is left as typed until Enter or leaving the field, which clamp it and write it back in the field's format.

## Units, stepper icons and focusable steppers

- **`unit`:** text after the number ("px", "ms") for a unit `formatOptions` cannot write. It is not part of the typed text, and is read with the value (`aria-valuetext` "12 px").
- **`decrementIcon` / `incrementIcon`:** Facet icons for the steppers (default minus and plus).
- **`steppersFocusable`:** the steppers become Tab stops after the input, each showing its name as a tooltip on focus; a press keeps focus on the stepper, unless it is disabled at its limit, when focus goes to the input.

## Formats and locales

Numbers are read and written with `Intl.NumberFormat` for `locale` (default: the browser's) and `formatOptions`: currencies, percents, units, fixed digits. People can type group separators, the local decimal mark, a typographic minus and digits of any script (full-width `４２` from a Japanese keyboard); text with any other character (`1e5`) is unreadable. Percents are typed as people say them: 20 means 20%, stored as 0.2.

## Forms

With `name`, the form receives the plain number ("1234.5"), whatever the text shows. Reset restores `defaultValue`; disabled fields are not submitted; `required` makes an empty field invalid.

<Canvas of={Stories.FormsGetThePlainNumber} />

## Scrubbing the label

`scrub` lets people drag the label sideways to change the value, as design tools do: one `step` every 4 pixels, ten with Shift. Escape during the drag puts the value back. The keys and steppers work as before, and a vertical swipe still scrolls on touch screens.

```tsx
<NumberField label="Width" defaultValue={100} min={0} max={500} unit="px" scrub />
```

## Behaviour and accessibility

- **Role:** `role="spinbutton"`, named by its label, with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and the formatted value as `aria-valuetext`.
- **Keyboard:**

| Key                    | Action                                      |
| ---------------------- | ------------------------------------------- |
| Arrow Up / Arrow Down  | One `step` up or down                       |
| Page Up / Page Down    | `largeStep` (10 steps) up or down           |
| Home / End             | To `min` / `max` (when set)                 |
| Enter                  | Commit the typed text                       |

- **Stepping:** stepped values snap to `step`, counted from `min`, and never pick up floating-point noise (0.1 + 0.2 is 0.3). The steppers are disabled at the limits.
- **Typing:** unreadable text goes back to the last value; values outside `min` and `max` are clamped.
- **Steppers:** not tab stops (the field is one stop, as in the APG pattern) unless `steppersFocusable`; their hit areas are at least 24px, 44px on touch screens; pressing one keeps focus in the field. Their names show as tooltips.
- **Mobile keyboards:** `inputmode` is `numeric` for whole non-negative numbers and `decimal` otherwise.
- **Labels:** "Decrease" and "Increase" are in `labels`.
- **Named and described from outside:** `aria-labelledby` names the field by other elements (a column heading) instead of its label; pair it with `labelHidden`. Your `aria-describedby` ids are read first, then the field's own description and error: they are merged, never replaced. `id` is the input's.

## Theming

NumberField uses TextField's tokens (`--cy-text-field-*`); digits are tabular so columns of numbers line up. `--cy-number-field-unit-color` colours the `unit` text (default `--cy-color-muted`).

# Link

An inline text link that takes the user somewhere. For an action that doesn't navigate, use [Button](?path=/docs/components-controls-button--docs).

<Canvas of={Stories.TonesAreReadable} />

## When to use

- Links inside sentences, help text and footers.
- `external` for pages outside your product.

**Use something else when:**
- it performs an action (save, delete): [Button](?path=/docs/components-controls-button--docs)
- it is a whole clickable panel: [Card](?path=/docs/components-structure-card--docs) with `href`

## Usage

```tsx
import { Link } from "@arshad-shah/cynosure";

<Link href="/docs">Read the docs</Link>
<Link href="https://example.com" external>Example</Link>
<Link href="mailto:hello@example.com" tone="neutral" size="sm">Email us</Link>
```

## External links

`external` opens a new tab with a safe `rel`, adds an external icon and announces "(opens in new tab)" to screen readers. Change that text with `labels.external`.

## With your router

`renderLink` renders the anchor with your router's link component. It receives Link's class and data attributes (its look), `aria-current`, the click handler, the ref and the content; spread them all onto the router's link and map `href` to its own prop. An `href` with a scheme that is not allowed (`javascript:`) arrives as `undefined`, and `external` arrives as `target` and a safe `rel`. Breadcrumbs takes the same `renderLink` for its crumbs; SideNav has its own.

```tsx
import { Link as RouterLink } from "react-router";

<Link href="/settings" renderLink={({ href, ...props }) => <RouterLink {...props} to={href ?? "/"} />}>
  Settings
</Link>
```

## Tone and size

`tone` defaults to `accent`; text uses each tone's readable text colour. `size` defaults to `inherit`, so the link matches the surrounding text; `sm`, `md` and `lg` set a fixed size.

## Underline

`underline` is `always` (the default), `hover` (on hover and keyboard focus) or `none`. Keep it in running text, where the underline is what tells a link from the words around it; take it off only where the place says it is a link (a navigation bar, a footer's columns, a card title). Every link keeps its focus ring.

## Behaviour and accessibility

| Input | Result |
| --- | --- |
| Click, <kbd>Enter</kbd> | Follows the link, or calls `onClick` |
| <kbd>Tab</kbd> | Focus with a visible ring |

- **Safe schemes:** `href` may be relative, `http(s)`, `mailto` or `tel`. Other schemes are not linked.
- **Ref:** the ref points at the anchor.

## Theming

Tokens: `--cy-link-underline-offset` and `--cy-link-underline-thickness`.

```ts
createTheme({ components: { link: { underlineThickness: "2px" } } });
```

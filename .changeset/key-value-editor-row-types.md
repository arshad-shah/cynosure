KeyValueEditor `rowTypes`: a Type select per row ("Type (token)") lets the user mark a pair Secret (its value masked, `secret: true`) or Text, and, with `allowFiles`, File (choosing it opens the file picker; Text takes the file away). Labels `type`, `typeText`, `typeSecret`, `typeFile`; token `--cy-key-value-editor-type-width`.

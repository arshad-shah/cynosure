## Contributing a recipe

Add a new MDX file under `docs/recipes/`:

- Give the `<Meta>` a `title` of `Recipes/<your slug>`.
- Write the recipe as a single code block with concise prose around it.
- Prefer Cynosure primitives over raw HTML in your examples.
- Verify the example compiles by pasting it into
  `apps/playground/` (when available) before submitting.

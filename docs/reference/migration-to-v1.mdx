# Migrating from 0.x to 1.0

There's nothing to migrate. v1.0 is the first public release — prior
`0.x` versions existed only in development. If you were consuming Lumen
from source or a local alias, install the npm package:

```bash
pnpm add @lumen/react @lumen/tokens
```

…and remove any workspace / local path references.

## What v1.0 ships

- Every component catalogued in the
  [Component inventory](https://github.com/arshad-shah/lumen/blob/main/README.md#component-inventory-what-every-single-component-means).
- Every foundation documented (tokens, theming, accessibility, RTL,
  motion).
- Eight priority recipes.
- `@lumen/react`, `@lumen/tokens`, `@lumen/themes`, `@lumen/core`, and
  `@lumen/icons` all released at the same semver, via linked changesets.

## Semver policy from here

- **Patch** — bug fixes, no API changes.
- **Minor** — new components, new props (additive), new variants. No
  breaking changes.
- **Major** — breaking changes. Requires a migration guide. Deprecations
  are announced at least one minor cycle before removal.

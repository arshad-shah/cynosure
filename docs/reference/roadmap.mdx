# Roadmap

## v1.0.0 (imminent)

Everything the 16 build phases cover. See
[`docs/specs/PROGRESS.md`](https://github.com/arshad-shah/lumen/blob/main/docs/specs/PROGRESS.md)
for the current state.

## v1.1 and beyond

Good things to signal, even if not yet scheduled:

- **Command palette** as a first-class component (today it's a recipe).
- **Toast collaborative API** — queue controls, grouped toasts.
- **Charts** — thin wrappers over Recharts / Visx with Lumen theming.
- **RichText / Markdown editor primitives**.
- **`@lumen/forms`** — a higher-level form package with built-in
  validation adapters.
- **`@lumen/vue`** — framework port. Not promised, but the clean
  `@lumen/core` separation keeps it feasible.

## Release cadence

- **Patch**: as needed, could be daily.
- **Minor**: monthly cadence.
- **Major**: rare, planned publicly via GitHub Discussions.

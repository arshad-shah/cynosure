# Installation

## Zero-config

```bash
npx cynosure init
```

Detects your framework (Next.js App Router, Next.js Pages, Vite, CRA, Remix),
installs the right packages, writes the single CSS import, and adds
`CynosureProvider` (plus a `providers.tsx` for Next.js App Router). Add
`--dry-run` to preview.

## Requirements

- Node 22 or newer for local development (Cynosure is authored against ESM and
  uses native TypeScript loading).
- **React 18 or 19** (peer dependency). Works with Next.js 13 / 14 / 15, Vite,
  CRA, and Remix.

## Manual install

```bash
pnpm add @arshad-shah/cynosure-react @arshad-shah/cynosure-tokens
# or: npm install … · yarn add … · bun add …
```

## Import the CSS — the one-line way

```ts
import '@arshad-shah/cynosure-react/all.css';
```

This single file bundles tokens (light + dark) and every component's CSS. For
most apps it's the right choice.

### The three-import way (granular control)

If you want to load tokens and component styles separately — useful when you
want to inline critical CSS, ship dark overrides conditionally, or control
cascade order yourself:

```ts
import '@arshad-shah/cynosure-tokens/css';          // design tokens, light theme
import '@arshad-shah/cynosure-tokens/css/dark';     // dark overrides (optional)
import '@arshad-shah/cynosure-react/styles.css';    // component styles barrel
```

### Per-component CSS

If you import per-component, your bundler wires up the CSS automatically:

```ts
import { Button } from '@arshad-shah/cynosure-react/button';
```

## Wrap your app

`CynosureProvider` composes `ThemeProvider`, `DirectionProvider`, `LocaleProvider`, and the global `TooltipProvider` in a single wrapper:

```tsx
import { CynosureProvider } from '@arshad-shah/cynosure-react';

<CynosureProvider theme={{ defaultTheme: 'system' }}>
  <App />
</CynosureProvider>
```

Everything is optional — pass only what you want to override. The individual
providers are still exported if you prefer to compose them yourself.

## Optional themes

```ts
import '@arshad-shah/cynosure-themes/terminal';
import '@arshad-shah/cynosure-themes/high-contrast';
```

## TypeScript

Cynosure is authored in TypeScript and publishes types with full JSDoc. If you
use `skipLibCheck: false`, make sure your `lib` includes `DOM` and `DOM.Iterable`.

## Peer dependencies

| Peer               | Range            | Required |
| ------------------ | ---------------- | -------- |
| `react`            | `>=18`           | yes      |
| `react-dom`        | `>=18`           | yes      |
| `react-hook-form`  | `^7`             | only if you import `@arshad-shah/cynosure-react/rhf` |

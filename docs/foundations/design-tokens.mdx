# Design tokens

Every visual decision in Lumen lives as a token in `@lumen/tokens`. Tokens
are authored in [W3C DTCG JSON](https://tr.designtokens.org/format/) and
compiled by Style Dictionary to:

- `dist/css/base.css` — `:root { --lumen-*: …; }` primitives + semantic
  tokens for the light theme.
- `dist/css/dark.css` — semantic overrides for dark mode.
- `dist/ts/*.ts` — typed TS constants (rarely needed by consumers; mostly
  used by Lumen internals).

## Categories

| Category     | Example                                    | Usage                         |
| ------------ | ------------------------------------------ | ----------------------------- |
| Colour       | `--lumen-color-accent-solid`               | Buttons, links, focus rings   |
| Space        | `--lumen-space-3`                          | Gaps, padding, margins        |
| Radius       | `--lumen-radius-component-md`              | Inputs, buttons, cards        |
| Shadow       | `--lumen-shadow-md`                        | Elevated surfaces             |
| Typography   | `--lumen-font-body-md-size`                | Font size + line-height pairs |
| Breakpoint   | `--lumen-bp-md`                            | Used by `LayoutProps`         |
| Focus        | `--lumen-shadow-focus-ring`                | Focus ring on interactives    |
| Motion       | `--lumen-duration-fast`                    | Transition durations          |

## Primitives vs. semantic

- **Primitive** tokens (`--lumen-color-blue-500`) are the palette.
- **Semantic** tokens (`--lumen-color-accent-solid`) are named by purpose
  and are what components consume.

Themes override semantic tokens. The palette stays put.

## Consuming tokens in your app

You rarely need to read tokens directly — most styling happens via Lumen
props or component variants. For custom CSS, reference the custom
properties:

```css
.my-hero {
  background: var(--lumen-color-surface-subtle);
  color: var(--lumen-color-fg-default);
  border-radius: var(--lumen-radius-component-lg);
  padding: var(--lumen-space-6);
}
```

## Overriding tokens

Scope overrides to a selector — `:root` for global, `[data-theme='mine']` or
a container class for local:

```css
[data-theme='brand'] {
  --lumen-color-accent-solid: #0f766e;
  --lumen-color-accent-solid-hover: #115e59;
}
```

See [Custom themes](?path=/docs/foundations-theming-custom-themes--docs)
for the theme-authoring flow.

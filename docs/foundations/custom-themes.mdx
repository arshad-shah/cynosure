# Authoring a custom theme

A Lumen theme is a CSS file that overrides the semantic tokens for a
`data-theme` selector. That's the whole API.

## 1. Define the overrides

Create `src/themes/brand.css`:

```css
[data-theme='brand'] {
  /* Accent family — buttons, links, focus rings. */
  --lumen-color-accent-solid: #0f766e;
  --lumen-color-accent-solid-hover: #115e59;
  --lumen-color-accent-soft: rgba(15 118 110 / 0.12);
  --lumen-color-accent-soft-hover: rgba(15 118 110 / 0.2);
  --lumen-color-accent-fg: #0f766e;

  /* Surface family — backgrounds, cards, inputs. */
  --lumen-color-surface-default: #ffffff;
  --lumen-color-surface-subtle: #f6fbfa;
  --lumen-color-surface-muted: #ecf5f3;

  /* Foreground family — body text, headings, borders. */
  --lumen-color-fg-default: #042f2e;
  --lumen-color-fg-muted: #134e4a;
  --lumen-color-fg-subtle: #5eead4;
  --lumen-color-border-default: #d6e4e1;

  /* Optional: signal the browser colour-scheme so native controls match. */
  color-scheme: light;
}
```

Only override what you need. Unset tokens inherit from `base.css`.

## 2. Ship it as a side-effect import

If you're authoring a theme package:

```json
{
  "name": "my-brand-theme",
  "exports": {
    "./lumen": "./dist/lumen.css"
  },
  "sideEffects": ["./dist/*.css"]
}
```

Consumers import it once:

```ts
import 'my-brand-theme/lumen';
```

## 3. Enable the theme

Add the theme name to your `ThemeProvider`:

```tsx
<ThemeProvider themes={['light', 'dark', 'brand']} defaultTheme="brand">
  {children}
</ThemeProvider>
```

`ThemeProvider` sets `data-theme="brand"` on `<html>`, and the override
CSS takes effect.

## Suggested coverage

Minimum tokens you probably want to override:

| Family      | Tokens                                                              |
| ----------- | ------------------------------------------------------------------- |
| Accent      | `*-solid`, `*-solid-hover`, `*-soft`, `*-soft-hover`, `*-fg`       |
| Surface     | `*-default`, `*-subtle`, `*-muted`                                  |
| Foreground  | `*-default`, `*-muted`, `*-subtle`                                  |
| Border      | `*-default`, `*-muted`                                              |
| Feedback    | `success.solid`, `warning.solid`, `danger.solid`                    |
| Focus       | `shadow-focus-ring`                                                 |

## Testing a custom theme

Lumen ships a contrast audit script that walks compiled CSS and asserts
WCAG 2.1 AA pairs. Add your theme to `scripts/audit-contrast.mjs` to
run the check against CI:

```bash
pnpm audit:contrast
```

## Scope to a subtree, not the whole page

Sometimes you want a theme only inside a specific container (for example a
"preview" area). Set `data-theme` on an element other than `<html>`:

```tsx
<div data-theme="brand">
  {/* children here render with the brand palette */}
</div>
```

All Lumen components read CSS custom properties through normal cascade, so
scoping "just works".
